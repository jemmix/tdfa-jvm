== SafeRE strategy attribution (SafeReMatchDiagnostics, observed) ==
# anchored alt/two/ip -> ONE_PASS; lit -> LITERAL; redos -> CHARACTER_CLASS
#   reject prefilter (required char 'b' absent — no engine ran)
# lettersRu/ipExtract find -> CHAR_CLASS|LITERAL start-accel + lazy DFA
# emailNoMatch -> CHARACTER_CLASS reject prefilter ('@' absent)
# caseiLit -> LITERAL (folded-literal scanner, 0.66 ns/char)
# find-all counting rows -> lazy DFA boundary, captures deferred (NONE)
# scan corpus has no '@'; Greek property syntax diverges per engine
#   (\p{Greek} re2j/tdfa ok, jur rejects; \p{IsGreek} jur/safere ok) —
#   luNoMatch ([\p{Lu}\d]{5,}) is the portable wide-class no-match row.
