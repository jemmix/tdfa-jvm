# BT19 — POSIX Submatch Implementation Plan

Reference: Borsotti & Trofimovich, *Efficient POSIX Submatch Extraction on NFA*
(SPE 2020, doi:10.1002/spe.2881). TeX at
`re2c/doc/papers/2019_efficient_posix_submatch_extraction_on_nfa/`.
C++ reference impl: `re2c/src/dfa/{closure_posix.h, posix_precedence.h,
tag_history.h}` and `re2c/src/nfa/{nfa.h, re_to_nfa.cc}`.

## Why we need this

Our engine implements BT22 TDFA(1), which covers leftmost-greedy (Perl) only.
BT22 §Conventions: *"POSIX disambiguation is more complex… extensively covered
in [BT19]."* The remaining 5 `testFowlerBasic` failures are all POSIX
leftmost-longest submatch cases that our heuristic DFS-order closure gets wrong:

| Case | Pattern | Want | Got |
|---|---|---|---|
| `basic.dat:23` | `a*(^a)` on `aa` | `g1=[0,1]` | `g1=[1,2]` (assertion-split, separate fix) |
| `basic.dat:29` | `(a*)(b?)(b+)b{3}` on `aaabbbbbbb` | `g3=[4,7]` | `g3=[4,9]` |
| `basic.dat:30` | `(a*)(b{0,1})(b{1,})b{3}` on `aaabbbbbbb` | `g3=[4,7]` | `g3=[4,9]` |
| `basic.dat:34` | `a*(a.\|aa)` on `aaaa` | `g1=[2,4]` | `g1=[3,4]` |
| `basic.dat:137` | `([abc])*bcd` on `abcd` | `g1=[0,1]` | `g1=[1,1]` |

Root cause: when paths merge in the DFA, the tag-tracking registers get
confused about which path was actually taken. BT19 solves this by computing
POSIX precedence structurally during ε-closure and baking the disambiguation
into the DFA — zero runtime cost.

## Architecture seam

BT22 line 891: *"Disambiguation decisions are embedded in TDFA; there is no
disambiguation at runtime."* The policy seam is `precedence` /
`epsilon_closure` in `Tdfa.Compiler`. We currently have:

- `epsilonClosure(seed)` — DFS exploration, accumulates `emptyMask`.
- `computePerStateOrder(seed, posMask)` — for `stopOnAcceptMask`.
- `stepOnSymbol` — intersects `emptyMask` → `requiredMask`, suppresses
  lower-priority configs past an accept (Perl mode only).
- `Config` has `pri` (worst ε-edge priority) for Perl-mode suppression.

For POSIX, we replace the priority machinery with BT19's structural
comparison. `pri` becomes unused in POSIX mode (already is); `emptyMask`
machinery stays for assertions (POSIX still needs assertions handled).

## Data structures to add

### 1. Tag heights

Each capturing group's open/close tags carry a **height** = the implicit
submatch index (parenthesis nesting level in the IRE — Indexed RE).
Opening and closing tags of the same group share the same height.
Greater height = deeper nesting.

Example: `((a)(b))` has 3 groups; heights 1, 2, 3 from outside-in.
Top-level alternation in `(a|ab)` — both alternatives' tags get the same
height (= the group's height).

Heights drive the trace comparison in `compare()`.

### 2. Nested-range M(m) table

For each tag m, `M(m) = (S, N)`:
- `S` = the submatch groups this tag reports to (for `pmatch` output).
- `N` = the range of nested tags (for negative-tag expansion).

For a capturing group with open=2i−1, close=2i:
`N(2i) = {tags of all groups nested inside group i} ∪ {2i−1, 2i}`.

Used during result extraction to expand a single negative tag into the
full set of "no match" tags.

### 3. U-tree (prefix tree of tag paths)

Persistent append-only prefix tree of tag sequences produced during
ε-closure. Common path prefixes are shared. A path is addressed by an
integer node index (0 = empty/root). Copying a path = copying an int.

Required operations:
- `empty()` — create root.
- `extend(node, tag)` — append child if not present, return child index.
- `pred(node)` — parent index.
- `tag(node)` — the tag on the arc from parent to node.
- `detach()` — unlink root's children for fresh closure (old lookups stay valid).

Sibling arcs sorted (or with sibling links) for the O(m²) prectable update.

### 4. H/P precedence table

Square table indexed by **origin state** (config from the previous step).
Each cell packs:
- **H (longest)**: minimal tag-height along the divergence (the "trace"
  value). 30 bits, signed. Range `[−MAX_RHO, +MAX_RHO]`;
  `MAX_RHO = 0x1FFFFFFF` = "infinity".
- **P (leftmost)**: −1/0/+1, 2 bits.

`pack(h, p) = (h & 0x3FFFFFFF) | (p << 30)`.
Diagonal `i==i` = `pack(MAX_RHO, 0)`.
Each step computes a new prectable of size = (current closure size)²
from the old one (size = previous closure size)².

### 5. Config (extend existing)

```
Config {
    state,           // NFA state
    origin,          // state index in previous step's prectable
    path,            // U-tree node index
    regs, h, l,      // existing (TDFA(1) determinization)
    emptyMask,       // existing (assertions)
    pri              // existing (Perl mode); unused in POSIX
}
```

## Algorithms

### compare(c1, c2, U, H, P) → (h1, h2, l)

l ∈ {−1, 0, +1}; negative = c1 wins.

```
compare(c1, c2):
    if c1.origin == c2.origin and c1.path == c2.path: return (∞, ∞, 0)

    fork = (c1.origin == c2.origin)              // same origin ⇒ fork inside this closure
    if fork: h1 = h2 = ∞
    else:    h1 = H[c1.origin][c2.origin]; h2 = H[c2.origin][c1.origin]

    u1' = u2' = ⊥                                // first diverging nodes
    while c1.path != c2.path:
        if c1.path > c2.path:
            h1 = min(h1, height(tag(U[c1.path])))
            u1' = c1.path; c1.path = U.pred(c1.path)
        else:
            h2 = min(h2, height(tag(U[c2.path])))
            u2' = c2.path; c2.path = U.pred(c2.path)
    if c1.path != ⊥:                              // common suffix above fork
        hh = height(tag(U[c1.path])); h1 = min(h1, hh); h2 = min(h2, hh)

    if   h1 > h2: l = −1                          // c1 wins (longest precedence)
    elif h1 < h2: l = +1
    elif not fork: l = P[c1.origin][c2.origin]    // defer to old leftmost table
    else:          l = leftprec(u1', u2', U)       // fresh fork: decide by diverging tags

    return (h1, h2, l)
```

Two-fingers walks the U-tree upward (parent index < child index invariant).
Running min of tag heights = the trace.

### leftprec(u1, u2, U)

Tiebreak at a fresh fork, comparing the two tags right after the fork:

```
leftprec(u1, u2):
    if u1 == u2: return 0
    if u1 == ⊥:  return −1     // c1 path ended ⇒ leftmost-wins
    if u2 == ⊥:  return +1
    t1 = tag(U[u1]); t2 = tag(U[u2])
    if t1 < 0 and t2 > 0: return +1     // negative (nil) loses
    if t2 < 0 and t1 > 0: return −1
    if t1 > 0 and t2 > 0:
        if t1 % 2 == 1: return −1       // odd = closing; closing wins over opening
        if t2 % 2 == 1: return +1
    return 0
```

PE order: `⊥ < ) < ( < nil` (end-of-path < closing < opening < nil).

### closure_gtop(C, U, H, P) — §5

Single-source shortest path on the ε-subgraph; "distance" is POSIX order
(closed-semiring min over path comparison). Queue ordered by
`topological_index(state)` (smallest first). Recommended starting point
(simpler than GOR1, near-identical speed in practice).

```
closure_gtop(C):
    result[q] = ⊥ for all q
    status[q] = OFFQUEUE

    for c in C:                                  // seed: keep better config per state
        if result[c.state] == ⊥ or less(c, result[c.state]):
            result[c.state] = c
            if status[c.state] != INQUEUE:
                push(queue, c.state, topo_index(c.state))
                status[c.state] = INQUEUE

    while queue not empty:
        q = pop_min(queue)                       // smallest topo index
        status[q] = OFFQUEUE
        (_, _, u, ...) = result[q]
        for (q →ε,α q') in ε-outgoing(q) [priority order]:
            c_new = (q', origin=q, U.extend(u, α), ...)
            c_old = result[q']
            if c_old == ⊥ or indeg(q') < 2 or less(c_new, c_old):
                result[q'] = c_new
                if status[q'] != INQUEUE:
                    push(queue, q', topo_index(q'))
                    status[q'] = INQUEUE

    return prune(result)                         // keep only final / RAN / FIN states
```

`less(a, b)` = `compare(a, b).l < 0`.

**Critical shortcut:** `indeg(q') < 2` ⇒ not a join point ⇒ skip the
comparison (right-distributivity: `X < Y ⇒ XZ < YZ`). Biggest perf win.

### update_precedence(C, U, H_old, P_old) → (H_new, P_new) — §8

**Naive O(m²·t):** for every pair (i,j) in the closure, call compare(c_i, c_j)
and write into H'/P'. Diagonal = `pack(MAX_RHO, 0)`.

**Complex O(m²):** DFS the U-tree once. Maintain `level[]` of items
`(origin, hidx, height)`. On the way back up from each child subtree, fold
`min(height, node_height)`; cross-branch pairs use old-table values.
Trickiest code in the algorithm — implement naive first.

### TNFA construction (POSIX-specific augmentations) — §9

- **IRE pass (mark+enum):** assign implicit submatch indices (= heights)
  to each group; explicit sets for groups that contain other groups.
- **Negative tags (ntag):** for each alternative `e1|e2`, prepend a no-match
  sub-automaton to each branch emitting one negative tag (the smallest even
  tag in the group's nested range). At result extraction, expands to set all
  nested tags to −1.
  *Purpose:* uniform match/no-match; guarantees U-tree prefix property
  (sibling sub-automata don't start with identical tagged transitions).
- **Bounded repetition:** unroll by chaining, not by parallel options.
  `a{2,5}` → `aa(ε|a(ε|a(ε|a)))`. Factors common prefixes.
- **Kleene star:** back-edge `(q_1, pri=1, ε, q_0)` (loop, higher priority)
  and exit `(q_1, pri=2, ε, q_f)`.

### Result extraction (POSIX offsets)

Walk winning path u to root. First time tag t is seen:
- t > 0: `d[t] = i` (current input position).
- t < 0: for each n in `M(|t|).N`, set `d[n] = −1`.

Use a `done[]` array so each tag is applied once.

## Implementation order

1. **IRE + heights** in `Parser`: add `height` to `Ast.Tag`; compute via
   `mark` (boolean "affects disambiguation") + `enum` (consecutive implicit
   indices). Top-down pass.
2. **Hierarchical tags**: extend `Tnfa.Tag` info to carry `height` and
   `nestedRange` (the M(m).N set).
3. **Negative tags** in `Tnfa.Builder`: for each `Ast.Alt`, emit `ntag`
   branches. For `Ast.Repeat` with `min==0`, the skip path emits an ntag.
4. **U-tree** (`UTree` class with `extend`, `pred`, `tag`, `detach`).
5. **`compare` + `leftprec`** with two-fingers.
6. **`closure_gtop`** using `compare` for `less` and `indeg<2` shortcut.
7. **`update_precedence` naive** (O(m²t)).
8. **Integrate** as POSIX policy in `Tdfa.Compiler`: when `!perl`, swap
   `epsilonClosure` for `closure_gtop`; replace DFS-order + suppression
   with BT19 precedence.
9. **Validate** against `re2c/src/test/posix/` corpus + our 5 failures +
   full regression (5.7M `testRE2Exhaustive` cases).

## Optimization phase (later)

- Replace naive O(m²t) prectable with complex O(m²) — single-pass DFS
  with `level[]` folding.
- Replace GTOP with GOR1 (Goldberg-Radzik two-stack) for ε-closure.
- Counting-sort on `node.finidx` for grouping configs by U-tree node.

## What NOT to do

- **No two-pass DFA+NFA scheme.** BT22 is unambiguous (lines 237–239):
  offsets for single-pass/AOT, tagged-strings only for multi-pass/JIT.
  The whole point of TDFA is zero runtime disambiguation cost.
- **Don't break Perl mode.** Perl uses the existing DFS-order closure +
  suppression. BT19 is an additive POSIX policy; gated on `disamb ==
  Disambiguation.POSIX`.
- **Don't skip the non-trivial-cycle rejection** in `map` (BT22 TODO).
  POSIX generates more copy ops than Perl; cycles matter more.
